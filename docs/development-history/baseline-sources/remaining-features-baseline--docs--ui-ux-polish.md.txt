# UI / UXの改善記録 — 2026-10-15

作業ブランチは`codex/ui-ux-polish`。モデル選択を左上、思考量を入力欄、会話本文をDiscord風の行にする構成を保ち、管理操作と固定表示の量を減らした。外部パッケージやネイティブエンジンの変更はない。

## 画面と操作

- 「モデルを探す」「モデル管理」「データ・バックアップ」「ダウンロード管理」は設定の「管理」タブへ集約。各画面は開いたままチャットを利用できる。モデル未設定時の案内と左上の追加ボタンも利用できる。
- サイドバーの「処理リスト」で、推論・ダウンロード・画像／文書の作成と準備を一覧する。実行中、予約日時順、再開待ち／失敗、完了の順に表示し、対象を開く・停止／取消・再開を操作する。
- ダウンロードは容量・割合・速度・残り時間を表示。推論は工程・経過時間・入力／生成量を表示する。回答の終了長は分からないため、推論の完了割合を作らない。文書生成は生成文字数も表示する。
- 本文の既定値を14 DIP、行間を22 DIPへ調整。サイドバー幅、発言行、フォームの余白、固定の説明行を縮めた。設定からアプリ全体の文字を100 / 115 / 130 / 150%へ拡大できる。
- 最小820×600の通常状態で会話欄334 DIP、履歴欄257 DIP。前回修正後の同じ監査条件の会話欄283 DIPに対し約18%広い。長文入力・添付・エラー等を重ねた状態では通常時より狭くなる。今回の監査では混雑時98 DIP、さらに分岐・処理計測・停止を重ねた状態で86 DIPだった。

## 検証記録

- `scripts/Verify.ps1`: Releaseビルド、書式、標準ライブラリによるチェック一式、Git空白検査。ログは`artifacts/ui-ux-polish-verify.log`。
- `--verify-ui-ux`: 管理導線、表示領域、未保存保護、再試行先、処理の進捗／予約順／取消、下書き分離、参照先固定、モデルフィルター、文字拡大、読書位置、履歴検索。`artifacts/ui-ux-polish/confirmed/`。
- 1,000会話／10,000メッセージ、10,000会話／100,000メッセージを生成して検索。入力処理と120msの待機を含む結果反映時間はJSONへ記録する。これはこの実機の合成データ測定で、全文をディスクから読む時間や全メッセージを同時表示する試験ではない。
- `--capture-dir artifacts/ui-ux-polish/regression-final`: 既存画面、検索モード、設定・プロジェクト範囲・資料・参加者等のWPF回帰が成功。
- `--verify-concurrent`: RX 9070 XTで4Bモデル2件の実ストリーム、片方の停止、会話ごとの順序、参照分離、予約後のモデル変更、再起動・再開が成功。取得併走は制御したHTTPストリーム16KBを実際の取得経路へ流した検証。`artifacts/ui-ux-polish/concurrent-model/concurrent-verification.json`。
- `--verify-skills`: 4Bモデルで自動適用、限定資料、版の固定、非モーダルのコード確認とCSV作成、文書生成、管理画面の操作が成功。`artifacts/ui-ux-polish/skills-model/skills-verification.json`。
- `scripts/Publish.ps1 -SkipNativeBuild -OutputDirectory artifacts/release-ui-ux-polish`: 単体exeを作成。サイズ132,715,885 bytes、SHA-256は`0B6AAE675672F31796854334B37D809F4AFA854808FBDB8F541B92C8410BB71D`。
- `artifacts/ui-ux-polish/portable/`へexeだけコピーし、インストール済み.NETを参照しない環境設定で起動。`verification/`で統合検証、`regression/`で既存画面回帰、`audit/`で生成中の選択・コード設定・誤再試行防止・混雑時の表示を再確認した。単体exeの10,000会話検索は入力処理13.1ms、120ms待機を含む結果反映176.1msだった。
- 同梱CPU／Vulkanのllama-serverとsd-cliの4本を展開して`--version`起動が成功。SHA-256は各既存ネイティブビルドと一致。共有ネイティブDLLは0、ライセンス通知ファイルは23。`portable/native-check.json`。ネイティブ構成を変更していないため、今回ネイティブの再ビルド・GPU演算照合は再実施していない。

描画PNGはWPFの論理寸法を96 DPI画像へ出力したもの。物理IME、全画面のキーボード巡回、スクリーンリーダー、OSのハイコントラスト、150%／200% DPI、複数モニター、メモリ不足、長時間運用は確認済みと扱わない。従来の画像認識・CPU/GPU画像生成の実モデル検証記録は保持し、今回その全経路を再実施したとは扱わない。
