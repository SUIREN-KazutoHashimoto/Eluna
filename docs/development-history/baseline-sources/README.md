# 開発途中のソース控え

旧PCの`artifacts/multi-monitor-baseline`と`artifacts/remaining-features-baseline`にあった、変更前・編集途中の控えを確認しました。生成済みの`bin/obj`を除くソース・資料130点のうち、91点はGit履歴内のblobと一致しました。残る39点は、通常のcloneだけでは原文を復元できないため、このフォルダーへ`.txt`として保存しています。

これらは旧版または編集途中の状態であり、**最新の実装は`src`・`tests`・`docs`です。** 最新ソースへ再適用したり、このフォルダーをビルド対象へ追加したりしないでください。新機能を実装する計画でもありません。失われそうだった履歴を保管するための保存です。

`manifest.json`に元の相対パス、保存ファイル、原文の容量とSHA-256、比較したGit blob IDを記録しました。`--`は元パスの区切りです。親の`.gitattributes`で原文の改行コードを保持するため、別PCでもSHA-256を照合できます。旧`Styles.xaml`の控えには空白だけの行が1行あり、この控えだけ空白検査の対象外として原文を保ちます。現行ソースの検査は変更しません。実行バイナリ、モデル、NuGet生成ファイルは含みません。
