# 開発版の使い方

プロフィール編集、プロジェクト＝サーバー、ボイスチャンネル、ウィンドウ共有とComputer Useの入口、および重なり対策を追加しました。[現行の仕様・操作と検証範囲](voice-channels.md)を参照してください。

主画面のモデル・思考量・検索・スキル・推論設定は左下のユーザー設定へ移動した。アカウントでモデルを管理し、入力欄は添付・メンション・絵文字を中心に使う。[新しい操作と移動先](discord-ui.md)を参照。

2026-10-16の統合改修で、通常会話もサーバー・チャンネル・DMへ整理した。アカウント、返信・スレッド、記憶の持ち越し、自由形ディベートの操作は[新しい使い方](workspaces.md)を参照。

Windows x64で`Eluna.exe`を起動し、設定 → 管理 →「モデルを探す」から公開GGUFを取得します。未設定時の案内からも開けます。取得はバックグラウンドで進み、完了したモデルを左上から選びます。モデル管理・データとバックアップ・ダウンロード管理も設定の「管理」タブにあります。標準.NETランタイムとCPU / Vulkanエンジンをexeに含めています。GPU利用には通常のGPUドライバーが必要です。詳しくは[モデルガイド](models.md)を参照してください。

## 会話と回答

入力欄で思考量と作業モードを選びます。通常はEnterで送信、Shift+Enterで改行します。設定でCtrl+Enter送信に変更できます。生成中は■またはEscで停止します。送信するとモデルを読み込み、右上の会話メニューから事前読み込み・メモリ解放もできます。

チャット領域が狭いときは、入力欄の「⋯」にスキルと検索・調査・参加者の設定をまとめます。複数の添付は横にスクロールして確認できます。思考量と停止・送信は入力欄に残ります。

回答はMarkdownの見出し、表、引用、リンク、コードとして表示します。回答の全文コピー、再生成、続きを生成、送信済み質問の編集を使えます。コードには言語名、色分け、コピー、折り返し切り替えを表示します。Markdownは対応する構文をWPFで描画する方式で、CommonMark全体への互換性は保証していません。

会話はDiscordを参考にした、アバターと名前を左へそろえる表示です。発言へマウスを重ねるか、キーボードで行内へフォーカスするとコピー・編集・再生成などの操作を表示します。モデル選択と入力欄の思考量の位置は維持しています。

編集・再生成では元の会話を残して新しい分岐を作ります。モデル選択欄の下にある分岐一覧から切り替えます。下書きは会話ごとに保存し、会話切り替え・再起動後に戻します。

## 履歴と長い会話

サイドバーの「プロジェクトなし」の右にある「⋯」からプロジェクトを作成・管理できます。作成後は選択欄で切り替え、その範囲の会話だけを表示します。新しいチャットも選択中のプロジェクトへ保存します。チャット上部にはナレッジの参照範囲を表示します。

プロジェクト管理の「資料」でファイルを追加し、「メモリ」で覚えておく事実を登録します。画像・PDFは画像対応モデルで読み取り、内容を確認してから参照を有効にします。変更は管理画面の「保存」で反映し、「キャンセル」では反映しません。通常チャットで使う共通メモリは設定の「メモリ」で管理します。回答をメモリに保存する場合は会話メニューから内容を確認して保存します。自動で保存メモリを書き換えることはありません。

初期設定の「プロジェクト限定」は、共通メモリ・共通指示・プロジェクト外の会話を使いません。作成時に「共通メモリも使う」を選べますが、別プロジェクトは参照しません。範囲は作成後に固定します。チャットの「渡したナレッジ」から、その回答に渡した資料・保存メモリ・同じプロジェクトの会話の抜粋を確認できます。全資料を毎回読む方式ではありません。詳細は[仕様](knowledge.md)を参照してください。

左側でタイトルと全分岐の本文を検索できます。一致する会話を選ぶと、本文が一致する分岐を開きます。履歴のメニューから名前変更、ピン留め、アーカイブ、削除を操作し、「保管済み」でアーカイブを表示します。

長い会話では推論に渡す古い部分を要約し、元の文章を保持します。右上の会話メニュー「会話の引き継ぎメモ」で内容を確認・編集できます。メモを空にすると、古い部分も再び元の履歴から推論へ渡します。必要なら次の生成で再要約します。要約が誤読していないかはメモで確認してください。

主画面は終了時の画面・位置・サイズ・最大化状態を次回起動時に復元します。保存先の画面がない場合は、接続中の画面内へ補正します。設定操作は不要です。詳しい規則と確認範囲は[ウィンドウ復元](window-placement.md)を参照してください。

設定から共通のカスタム指示、文字サイズ、行間、明暗テーマを変更できます。会話メニューには会話別のカスタム指示もあります。生成中に古い文章へスクロールしてもその位置を保ち、「最新の回答」で戻れます。

設定 → 管理 →「データ・バックアップ」の「全体バックアップ」で、スキル本体・生成物・予約も含めてZIPへ保存できます。モデル本体の同梱は選択式です。ZIPからの復元は現在のデータを退避したうえで置き換え、アプリを再起動します。未完了の依頼は再開待ちとなります。履歴JSONの取り込み・書き出しと世代復元は別タブに残しています。[バックアップの仕様](backup.md)を参照してください。

設定の「ライセンス」タブでは、Eluna本体、llama.cpp、stable-diffusion.cpp、配布exeに同梱したランタイムや関連ライブラリの通知を一覧から選び、原文を読めます。名前・ファイル名で絞り込み、本文でCtrl+A / Ctrl+Cを使えます。インターネット接続やモデルの読み込みは不要です。閲覧後は「閉じる」で戻れます。モデル自体の利用条件は別のため、取得画面と配布元のモデルページで確認してください。開発ビルドでは本体・両エンジン・第三者コードの説明の4件、配布版ではネイティブ資材に含む通知も表示します。

| 操作 | キー |
| --- | --- |
| 新しい会話 | Ctrl+N |
| 履歴検索 | Ctrl+F |
| サイドバー切り替え | Ctrl+B |
| 全体を停止 | Esc |
| 最新の回答へ戻る | Ctrl+End |
| 最新の回答を再生成 | Ctrl+Shift+R |
| 最新の回答をコピー | Ctrl+Shift+C |

## 保存、復元、診断

履歴を自動保存し、生成済みの途中文章も約1秒間隔で保存します。前回の生成が中断していた場合は本文と中断表示を復元します。最後の保存から終了までの文章は復元できない場合があります。

「データ・バックアップ」では最大20世代の復元、履歴JSONの書き出し・追加読み込み、診断情報の書き出しを使えます。復元前の履歴も保管します。JSONの読み込み上限は100MBです。会話メニューから現在の分岐をMarkdownへ書き出せます。診断にはOS、バージョン、計算設定、メモリ量、例外の種類を記録し、会話本文・カスタム指示・モデル内容を含めません。

履歴JSON・バックアップにはプロジェクトの資料と保存メモリも含めます。取り込みではプロジェクトを新しいIDで追加し、既存の同名プロジェクトへ混ぜません。共通メモリも取り込む場合だけ、取り込み画面でチェックします。バックアップの復元はプロジェクトと共通メモリもその時点へ戻します。

状態欄には読み込み、初回出力時間、入力token数、生成速度、メモリなどを表示します。エラー時は説明と再試行を使い、必要ならモデルを小さくする・記憶長を減らす・CPUへ切り替える操作を試します。更新確認は設定から開き、公開リリースの内容を確認して配布ページへ移動します。自動でexeを置き換える処理はありません。

## 検索、調査、議論

通常の「チャット · 自動検索」でも、必要に応じてWeb検索を使います。「検索して」と頼むか「Web検索 · 必ず」を選ぶと検索を試みます。「検索しない」では検索・ページ取得を行いません。追加質問では直前の質問の一部を検索語に含めるため、秘密を含む会話では検索しない設定を使ってください。「深掘り調査」「ディベート」も入力欄から選べます。[調査機能ガイド](research.md)に、外部へ送る情報、計画の編集、役割別モデル、上限、停止・再開、出典、Markdown出力を記載しています。

現在は機能一覧01〜29の開発版です。[実装・検証の台帳](implementation-status.md)で確認済みの範囲と、実IME・DPI・別PCなどの未確認事項を分けて記載しています。

## 推論中の並行作業

作業モードの「Computer Use」、入力欄の「＋」、または`@Computer`の依頼からWindowsアプリの操作を開始できます。操作するアプリを許可すると、通常のマウス・キーボード操作を自動で進めます。会話内で計画・プレビュー・進捗・重要な操作の確認・履歴を表示します。同じ会話で追加指示を送り、一時停止・再開・自分で操作する切り替えもできます。チャットを切り替えても続き、別のComputer Useは順番を待ちます。停止は■またはCtrl+Alt+Esc。詳細は[Computer Use](computer-use.md)を参照してください。

推論や取得の途中でも履歴・プロジェクトを切り替え、新しい質問を送信できます。空きがなければ予約し、同じ会話では先行する回答を待ちます。サイドバーの「処理リスト」で進捗・予約順を確認し、対象を開く・停止・キャンセル・再開を操作できます。画像・文書の生成も保存・再開でき、画面を閉じても続きます。設定の一般タブでチャット推論・取得・画像／文書生成それぞれの同時数を1〜4件へ変更できます。初期値は各1です。メディア予約の保持範囲を含む詳細は[並行作業ガイド](concurrent-work.md)を参照してください。

設定の「アプリ全体の文字の拡大」で100〜150%へ拡大できます。会話本文の文字・行間は別に調整できます。管理画面や設定に未保存の変更があれば、閉じる前に保存・破棄・編集継続を選べます。生成中の本文を選択している間は表示更新を保留し、選択を解除するか更新ボタンを押すと続きを反映します。

## スキルを使う

入力欄の「スキル」から、自動適用・指定のみ・オフを会話ごとに切り替えます。管理画面ではSKILL.md／ZIPを取り込むか、名前・用途・手順を書いて作成できます。「標準スキルを追加」で文章推敲・議事録・数値集計の例を追加できます。

明示指定は一覧で選ぶか、`/number-summary 数値4、8、12を集計して`のように入力します。回答の使用スキルボタンから、手順・資料・実行結果を確認できます。補助コードは初期設定で内容と入力を確認してから実行します。プロジェクトの範囲と対応する形式・実行環境は[スキルガイド](skills.md)を参照してください。
