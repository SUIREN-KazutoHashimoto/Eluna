# Eluna 0.1.0beta

Windows x64向けの開発プレリリースです。develop向けPRの最新ソースを`v0.1.0-beta`へ固定し、内部バージョンは`0.1.0-beta`とします。正式版としての品質保証や、すべてのモデル・PC環境での動作確認が完了した版ではありません。

## 主な変更

- Discordを参考にしたサーバー・チャンネル・DM・スレッド、プロフィール、メンション、招待、閲覧・発言権限。ナレッジ・記憶の参照範囲も管理できます。
- アカウント間の会話と自由形ディベート、指名・割り込み・リアクション、条件を設定した自発的な会話。初期12アカウント、サーバー最大50人、個別の性格と生成設定に対応します。
- 絵描きスキルを持つアカウントがプロンプトを作り、同梱の画像生成エンジンで画像を返します。モデルの重みは別途必要です。
- チャットからのComputer Use、マウス・キーボード操作、操作中の画面効果・一時停止・停止、VC参加者とウィンドウ共有。
- 未読・発言検索・ピン・引用・リアクション、カラー絵文字、入力欄・スクロール・最大化時の配置を改善しました。
- Web検索の資料を使う返答と出典表示、本文と分離した開発者ログ、収集レベル・保存期間・ZIP書き出し。
- 単体exe、ユーザー単位のインストーラー、正式版／開発版を選べる更新、配布物のハッシュ検査、更新失敗時の復旧。

## 配布ファイル

- `Eluna-Setup.exe`：インストーラー。管理者権限や.NET・SDKの事前導入は不要です。
- `Eluna.exe`：インストールせず起動する単体exe。CPU / Vulkanのllama.cppとstable-diffusion.cppを同梱します。
- `update-manifest.json`：版・開発トレイン・データ形式・容量・SHA-256。
- `SHA256SUMS.txt`：各配布ファイルのSHA-256。

モデルは同梱していません。初回に設定の「モデルを探す」から取得してください。exeにAuthenticode署名はありません。設定と会話の通常の保存先は`%LOCALAPPDATA%\Eluna`です。初回移行前のバックアップを推奨します。現行の形式5は旧形式1〜4を上書きせず読み込みます。

## 検証と制約

C#のビルド・整形・コンソール回帰と配布物検査、隔離した保存先でのWPF起動・インストール／更新・復旧を確認する構成です。CPU / Vulkanの各エンジンの展開・起動、Radeon RX 9070 XTでのCPU参照との演算一致、ローカルモデルによる会話・自発的な開始・画像生成は今回の開発ソースで確認しました。詳細は[検証台帳](../social-autonomy-status.md)を参照してください。

別PC、物理IME・実DPI切り替え・スクリーンリーダー、実環境のアンインストール登録、電源断、49アカウントの長時間会話、GitHubの自動公開ワークフローは未確認です。会話の自然さ・ツール利用・画像認識はモデルに依存します。Web検索でも根拠を確認できないときは、未確認である旨を返します。Windows側にないカラー絵文字は標準の代替表示になります。
