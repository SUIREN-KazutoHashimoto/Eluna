## 回答の品質

Web検索ではリリースページのWindows x64 / arm64 (Vulkan)という本文を引用し、対応バイナリの存在を説明できた。4B/2Bの議論でも同じ一次資料を引用できた。指定モデルによって検索語や結論は変わる。

一方、4Bの深掘り調査は同じ資料を読んでも「Windows版に含まれない」という誤った内容を未確認の結論として出した。4Bだけの議論は、公式のリリースページにあるバイナリを「コミュニティビルドの可能性が高い」と推測した。事実として確認できない節には未確認・推測の表示が付くが、その内容が妥当とは限らない。引用が本文に存在することと、資料を正しく読解したことを区別する必要がある。

引用の不一致や出典のない事実の節を除去する処理、原典候補を優先する処理は実装している。モデルの読解誤りを完全に検出するものではない。同じモデルの議論や、思考量・検索量の増加によって品質が向上すると結論付ける評価にはなっていない。現在は機能を追加した開発版として扱う。

## 評価の限界

一つの問いによる動作と資料対応の確認であり、網羅的な品質試験ではない。日本語の一般質問、異なる領域、時間依存の問い、発行日が不明な資料、反対する一次資料、長い議論での評価は残る。本文取得はHTML / テキスト / XMLが対象で、PDF・ログイン・JavaScript依存のページには制約がある。外部の検索サービスの制限や順位も変動する。
