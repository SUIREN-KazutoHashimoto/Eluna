# 提示されたDiscord画面に合わせた主画面の調整

2026-10-17、`codex/discord-experience`。オーナーが提示したElunaとDiscordの画像を基準に、主画面の配置・寸法・読みやすさを調整する。テーマの色・Nitro・サーバー固有の装飾は比較対象にしない。外部パッケージは追加しない。

## 画像での違いと変更

| 場所 | Elunaで目立った違い | 調整 |
| --- | --- | --- |
| 上端 | 常時クイックスイッチの操作説明が出ている | サーバー名を中央へ表示し、クリック／Ctrl+Kで従来の検索を開く。長い名前は省略 |
| 左側 | チャンネル欄が細く、名前や状態を読みづらい | 通常幅を304 DIPへ拡大。狭い画面では224 DIP。サーバー追加は一覧の直後へ置く |
| チャンネル一覧 | 種別を文字記号で表し、テキストとVCの境界が弱い | テキスト・VC・DMをベクターアイコンで表示し、既存の種類別グループを見分けられるようにする |
| ヘッダー | サイドバー開閉、説明文、招待等が主張し、左右の幅が揃わない | 広い画面ではチャンネル名を左へ寄せ、ピン・招待・メンバー・検索を右へ揃える。狭い画面の開閉とピン一覧への従来の入口も維持 |
| 発言 | 名前・アバターが小さく、返信の引用が名前の下にある | 発言者名16、アバター40、名前と本文の開始位置を揃える。引用は発言者の上へ移し、クリックで元発言へ戻る |
| 本文 | 標準サイズ14で全体に小さく見える | 新規・未指定データの標準本文を16／行高22へ変更。既に保存された文字サイズは維持 |
| メンバー | 一覧が細く、常設の招待行が場所を取る | 通常幅264 DIP、名前14に変更。招待はヘッダー等の既存操作から開く |
| 左下 | 本人のプロフィールがチャンネル欄の内側に収まり、最大化時に見えない | サーバー列とチャンネル列をまたぐ下部パネルへ移す。プロフィール・設定と、接続中に使えるマイク・読み上げ切替を配置 |
| 入力欄 | 画面下へ隠れ、案内・余白・Placeholderの位置も合っていない | 下端に収め、送信キー案内は入力欄のツールチップとアクセシビリティ用説明へ移す。PlaceholderはTextBoxと同じ字号・位置で、実テキストとIME状態から表示を決定 |
| VC表示 | チャンネル名と説明が上下に重なり高さを使う | 参加前の案内を一行のコンパクトな配置へ変更。参加・マイク・共有・退出等の既存の動作は引き続き使用 |

1枚目はVCのテキスト会話、2枚目はテキストチャンネルなので、VCの参加操作そのものは必要な場所へ残す。未接続のマイク・読み上げボタンは実行できない状態で表示する。架空のオンライン人数・活動・共有状態は作らない。

最大化時は、カスタムタイトルバー用の`WM_GETMINMAXINFO`で、対象モニターの作業領域を物理座標のまま適用する。タスクバーの位置や負のモニター座標を考慮し、アプリの入力欄・プロフィールが作業領域を越えないようにする。OS設定は変更しない。

## 確認方法

`scripts/Verify.ps1`と、`scripts/Test-DiscordExperience.ps1`の9種類のWPF回帰を使う。`--verify-discord`には、今回の配置・Placeholder・引用・3440×1392の描画・ネイティブ最大化の確認を追加した。

描画は架空の会話と隔離データで行い、提示された利用者の会話本文やアカウント情報はリポジトリへ追加しない。IMEはWPFの開始／確定イベントでの確認で、物理IME入力ではない。別DPI・タスクバー位置・負の座標は座標計算の検証と実機確認を区別する。
