# Discordを参考にした主画面

プロフィール編集、プロジェクト＝サーバー、ボイスチャンネル、ウィンドウ共有とComputer Useの入口、および重なり対策を追加しました。[現行の仕様・操作と検証範囲](voice-channels.md)を参照してください。

2026-10-16、codex/discord-shellで主画面を再構成。左端のサーバー列、チャンネル一覧、会話、右側のメンバー一覧、左下のユーザー設定へ操作を整理した。モデル中心のツールバーを外し、アカウントとの会話を中心にした。

配置は[Discordのユーザー設定ガイド](https://support.discord.com/hc/en-us/articles/206346498-Where-can-I-find-my-User-Server-Message-ID)と[アプリ・メンバー一覧のガイド](https://support.discord.com/hc/en-us/articles/21334461140375-Using-Apps-on-Discord)を参考にした。アプリ名・サービスはElunaのままで、外部Discordへの接続は追加していない。画像素材や外部UIライブラリを追加せず、WPF標準機能と描画で実装した。

## 主画面

- サーバー列、サーバー名メニュー、チャンネル一覧、1行のチャンネルヘッダーを配置。同じ役割だったプロジェクトの選択欄を外した。
- ヘッダーのモデル選択・追加、宛先選択、分岐選択、参照範囲の設定を外した。
- 入力欄はファイル添付、メンション、絵文字、送信・停止に絞った。作業モード、思考量、スキル、参加者・推論の設定、GPU・トークンなどの数値は出さない。
- 発言はアバター、名前、APPバッジ、時刻、本文を中心に表示。モデル名・思考モードは設定のメッセージ詳細へ移した。引用、添付、出典、生成物、Computer Useの操作確認は会話から扱える。
- 幅1,120以上では右にメンバー一覧を表示し、ボタンで閉じられる。狭い画面は同じボタンからポップアップで開く。空白を含む名前のメンションにも対応。
- 入力中／確認待ち／次の発言待ちを控えめに表示。詳しい進捗・予約・議論の操作は設定の処理リストへ移した。
- 空の会話に紹介を表示。本文追加時に紹介が残って重なる問題も修正した。
- タイトルバー、最小化・最大化・閉じるもWindowChromeで揃え、サイズ変更・位置復元は維持した。

## 設定の移動先

左下の歯車からユーザー設定を開く。カテゴリを左側に並べ、内容と保存操作を分けた。

| カテゴリ | 主な操作 |
| --- | --- |
| 外観・操作 | 明暗、文字サイズ・行間、拡大率、送信キー |
| アカウント | 名前・アイコン・モデル・指示・専門分野・履歴・メモリ |
| モデル・データ | モデル検索・管理・読込／解放、ダウンロード、バックアップ |
| AI・実行 | CPU/GPU、同時実行数、コンテキスト、スリープ抑止、共通指示 |
| チャンネル | 作業・検索モード、思考量、既定の応答アカウント、参加者・参照範囲、分岐、個別指示、引き継ぎメモ、再生成、メッセージ詳細 |
| スキル | 管理・取り込みと対象チャンネルの適用方法 |
| 画像・文書 | 画像認識モデル、画像・文書生成、回答の文書化 |
| 処理リスト | 進捗・予約・停止・再開と議論の進行・参加者変更 |
| 共通メモリ・ライセンス | 既存の管理・表示 |

モデルはアカウントで割り当てる。「ダウンロードして使う」も、ブラウザーを開いた時の応答アカウントへ割り当てる。既存のモデル未指定アカウントは互換の既定設定を保持する。

チャンネルの設定は開いた時の対象へ保存する。別チャンネルへ移動した後の誤保存を防ぎ、予約済みの依頼は予約時の設定を使う。設定・アカウントの未保存変更を保護し、子のアカウントを編集中に親の設定を閉じても破棄の確認を行う。基本のチャンネル・DM作成画面にはモデルや記憶の設定を出さない。

## 検証

```powershell
./scripts/Verify.ps1
./artifacts/release-discord/Eluna.exe --verify-discord artifacts/discord-portable/ui --data-dir artifacts/discord-portable/ui/data
./artifacts/release-discord/Eluna.exe --capture-dir artifacts/discord-portable/regression --verify-ui-ux
```

専用データを使い、主画面のAI選択欄の除去、設定からのモデル割り当て、チャンネル設定の保存・誤保存防止、メンション・絵文字・下書き、空の画面、未保存の子画面、明暗、最小820×600／設定660×500、文字130%をWPF操作・描画で確認した。既存の履歴・処理順・保存・スキル・ライセンス等のチェック、実モデルの会話・議論・生成も通過した。

記録・画面はartifacts/discord-portable/、自動チェックはartifacts/discord-verify.log。別PC、物理IME、OSのドラッグ、高DPI・複数モニター、スクリーンリーダーの実機確認は含まない。サーバー・履歴・メモリ・モデル本体の保存形式は変更していない。

単体exeを別フォルダーへ単独コピーし、インストール済み.NETを参照しない設定で全UI検証と実モデルを実行した。UIは ui/、既存画面・ライセンス・資料等は preview/、密度・履歴性能・処理順等は regression/、Qwen3.5-4B / Vulkanでの会話・記憶分離・全員宛て・両方式の議論・割り込み・追加検索・文書生成は live/ に記録する。CPU/Vulkanの llama-server・sd-cli の4エンジンは native.json、exeのSHA-256は exe.json。
