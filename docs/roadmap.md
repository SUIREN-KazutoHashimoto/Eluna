# 開発ロードマップ

各段階の完了条件を満たしてから次へ進みます。日時や性能数値は、実機での確認前に確約しません。

2026-10-15に検索、深掘り調査、マルチエージェントディベートの要望が追加されました。承認された代替方針に従い、検索はC#の自前基盤を採用しています。[機能一覧01〜29](product-backlog.md)を基準に開発版へ機能を追加しました。[実装・検証の台帳](implementation-status.md)に到達点を記載し、正式リリースの判定とは分けています。

## 0. 開発基盤

WPFの起動、C#の外部パッケージを増やさないビルド、Windows CI、固定したllama.cppのCPU / Vulkanビルド、ブランチ運用を整える。承認済みのVulkan SDKでGPUをビルドし、実機で演算を確認する。GitHub上の保護ルール適用は別途必要です。

## 1. ローカルチャットの最小機能

GGUFの選択、サーバー起動・終了、状態表示、ストリーミング応答、生成停止を実装する。日本語IMEが誤送信せず、推論中も画面が操作でき、失敗時に再試行できることを完了条件にする。

プロトタイプではモデル検索・取得、ストリーミング生成、停止、サーバー管理を実装し、実モデルで確認済み。日本語IMEの実機操作確認は残っている。

## 2. 日常使いの機能

会話の保存・復元、新規会話、検索、名前変更、削除、設定保存、モデル切り替え、コピーを追加する。再起動して会話が戻り、データ破損や保存失敗から回復できることを確認する。

開発版では履歴検索・名前変更、Markdown、質問編集と分岐、モデル削除・設定・保存先移動まで追加しています。保存・復元とモデル管理を実モデル・自動検証で確認しています。

## 3. デザインと操作品質

会話・履歴・設定のレイアウト、共通スタイル、テーマ、キーボード操作、DPI、長文表示を仕上げる。機能開発の段階からdocs/design.mdの基準を使い、この段階で全体の一貫性を確認する。

## 4. 配布と安定性

実機でCPU・GPU・メモリ・対応モデルを評価し、Windowsの対応範囲、配布方式、ライセンス表示を決める。Vulkan以外の追加SDKが必要なGPU対応は事前相談する。SDKの入っていないWindows環境でもGPU推論を確認し、起動・生成・保存・終了を確認してから初回リリースとする。

## 追加の検索・調査・議論機能

検索・本文取得・出典管理は.NET標準機能で実装し、深掘り調査とディベートで共用しています。検索回数・資料数・生成量・時間の上限、停止・保存再開を確認しています。原典への到達、読解と根拠の対応、議論の有効性を評価し、取得できない資料や未確認事項を結果へ残します。SearXNG本体を再検討する場合は、具体的な追加依存と配布条件を先に相談します。
