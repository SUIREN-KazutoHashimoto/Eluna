# ディベート参加者と会話表示の変更

作業ブランチは`codex/debate-drag-discord`。既存の未コミット変更を保持してdevelopから作成した。新しい開発版は`artifacts/release-debate-discord/Eluna.exe`で、以前のexeは上書きしていない。

## 参加者の変更

入力欄で「ディベート」を選び、「参加者」を開く。左のモデル一覧から、右の参加者カードへドロップするとモデルを変更する。空き部分・追加欄へのドロップは新しい参加者を追加する。⠿ ハンドルからのドラッグで発言順を変更し、カードの上半分・下半分に挿入位置を示す。リストの端ではスクロールする。左下の削除欄へ参加者をドロップすると外す。

人数は2〜6名。最大人数でも既存参加者へのモデル変更はできる。各モデルの＋、上下移動、削除ボタンも使える。「編集」で名前・役割・モデルの詳細を開く。現在取得されていないモデルの割り当てを、設定を開いただけで別のモデルに置き換えない。

変更はウィンドウ内の下書きで保持し、「保存」時に反映する。実行中の議論や過去の発言は書き換えない。人数・ラウンド・生成量などの実行方法は従来どおりで、順次推論する。外部パッケージを追加せず、[WPF標準のドラッグ＆ドロップ](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/drag-and-drop-overview)を使う。ほかの設定画面や外部アプリのドラッグデータは受け付けない。

## 会話表示

中央は丸いアバター、発言者名、AI表示を付けた左そろえの行に変更した。吹き出しをなくし、行のホバー・キーボードフォーカス時に操作を出す。ダーク・ライトの双方で会話面と入力欄の色を設定し、未開始時の案内も左へそろえた。

モデル選択は左上、思考量は入力欄のまま。メッセージ、分岐、生成・停止、コピー、Markdown、コード、仮想化は既存の処理を使う。存在しない発言日時を表示するためのデータ追加は行っていない。
